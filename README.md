
# My Personal Portfolio Website

## About the Website
This is my personal portfolio website created for INFR3120.
It introduces me, shows my academic projects, and provides my contact information.

## Website Pages
- Home: A short welcome and introduction.
- About Me: Information about me, my photo, and my introduction video.
- Projects: Four projects from my university coursework.
- Contact Me: My contact details and a contact form.

## Responsive Design
I used three CSS files to make the website responsive.

- mobile.css: Screens 480px wide or smaller.
- tablet.css: Screens from 481px to 959px.
- laptop.css: Main styling for the website, including laptop screens.

I chose these screen sizes to make the website easier to use on phones, tablets, and laptops.

## Colours and Gradients
I used dark blue, medium blue, light blue, and white to create a simple and professional appearance.

The main colours are:
- Dark blue: #1e3a5f
- Medium blue: #285c88
- Light blue: #e8f0ff
- White: #ffffff

I used a normal linear gradient on the page background and a 45-degree angled linear gradient on the navigation menu.

## Technologies Used
- HTML5
- CSS3

## External Code
The website uses basic HTML and CSS techniques covered in class. No external code libraries or frameworks were used.
